# Networking Lab Evidence

This directory records my practical work through the networking modules in the KubeCraft learning path.
In particular, [Drew Elliott’s ](https://github.com/drewelliott/kubecraft)[`kubecraft`](https://github.com/drewelliott/kubecraft)[ repository](https://github.com/drewelliott/kubecraft).

Rather than marking exercises as complete without context, each module contains evidence of what I built, what I observed and how I verified it. Depending on the exercise, that may include:

- answers to the exercise questions;
- network diagrams;
- selected command output;
- automated test results;
- break/fix investigations;
- troubleshooting notes;
- explanations of packet flow and Linux networking behaviour;
